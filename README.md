# 高端養老客群人格匹配系統 PWA

## 功能說明
本應用為高端養老銷售人員提供客戶人格匹配分析工具，整合：
- **大五人格問卷 (BFI-10)** — 10題科學化人格評測
- **星座匹配分析** — 十二星座契合度評估
- **生肖相生相克** — 傳統生肖適配分析
- **客銷適配建議** — 針對高端養老客群的專業銷售策略

## iPhone 安裝 (PWA)
1. 用 Safari 開啟 https://jp169zx-gh.github.io/match/
2. 點擊底部「分享」按鈕 (方框加箭頭圖示)
3. 選擇「加入主畫面」
4. 點擊「加入」完成安裝

## 文件結構
- `index.html` — 主應用（單頁應用）
- `manifest.json` — PWA 設定
- `sw.js` — Service Worker（離線支援）
- `icon-192.png` — 應用圖示 (192x192)
- `icon-512.png` — 應用圖示 (512x512)

## 技術規格
- 純 HTML/CSS/JavaScript，無需框架
- 支援離線使用（Service Worker 緩存）
- 響應式設計，優化 iPhone 顯示
- 中文繁體界面
